# Local font assets

- `lufga/`: original OTF family from the user-supplied `lufga-www.Dfonts.org.zip`. The archive included a download-site readme but no font license; the readme is preserved. License permission has not been verified.
- `clash-grotesk/`: original OTF family from `ClashGrotesk_Complete.zip`. The included `FFL.txt` license is preserved alongside the fonts.

ZIP archives, promotional URL shortcuts, and duplicate web/variable formats were removed after verifying the extracted OTF bytes. Only faces listed in `src/theme/fonts.ts` are loaded by the app. Other original OTF weights are retained for future typography changes.
