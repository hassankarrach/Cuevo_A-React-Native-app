# Winners 2005 catalog artwork

Five distinct release covers fetched on 2026-11-18 from Apple's artwork CDN using the public iTunes Search API. The catalog is `src/data/songs.json`; each entry preserves its source page, provider ID, original artwork URL and retrieval date. `src/data/songs.ts` pairs metadata with bundled React Native image sources.

These are existing release covers, not generated artwork. Artwork remains the property of its respective rights holders; retrieval does not establish redistribution rights. Review provider artwork usage terms before publishing.

Only metadata and JPEG cover images were fetched. Audio, previews and playback integration are not included. Provider release dates describe the catalog releases and may differ from original performances or uploads. Durations are rounded to the nearest second for display.
