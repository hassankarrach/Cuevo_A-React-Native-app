# Provider artwork

`google-g.png` is Google's original full-color G icon downloaded from:
https://developers.google.com/static/identity/images/g-logo.png

Branding reference: https://developers.google.com/identity/branding-guidelines
Displayed unmodified on white, inside a full-width native sign-in button. Authentication is not connected yet.

## Cuevo welcome wordmark

`cuevo-flow-wordmark.png` is the user-selected flat, connected orange wordmark generated with imagegen on 2026-11-21. Copied without pixel or alpha changes. Used on the welcome page; original assets/logo.png remains the source for native app configuration.

## Installed Cuevo app icon

`cuevo-app-icon-orange-v3.png` is selected in `app.json` as the native app icon. It is the orange design with the white Cuevo wordmark and peach ribbon. Earlier icon variants remain as design references. Native icon changes require rebuilding the installed app; Expo Go retains its own icon.
